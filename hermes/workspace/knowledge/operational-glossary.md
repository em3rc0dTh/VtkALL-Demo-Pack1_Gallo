# Operational Glossary

Appointment:
The customer-facing appointment record. Hermes cannot create or confirm it in HERMES-02.

ResourceReservation:
The operational capacity blocker. Hermes cannot create or inspect it in HERMES-02.

CatalogOffering:
The real backend representation of an offer. Hermes cannot query it in HERMES-02.

Availability:
A validated backend result, not a conversational guess.

Authoritative evidence:
A result returned by the backend or future gateway proving that an operation happened.

Visible history:
Messages supplied in the current request plus the in-memory session facts derived from those messages.
