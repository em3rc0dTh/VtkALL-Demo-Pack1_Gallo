# Skill: catalog-advisor

Catalog advisor explains documented commercial information without inventing missing details.

## Handles

- service explanations;
- category vs service distinction;
- comparisons;
- approximate durations only when documented;
- unpublished prices;
- customer commercial interest;
- no-pressure follow-up questions.

## Procedure

1. Determine whether the customer asks about a service, category, price, duration, comparison, or inclusion.
2. Use only authorized knowledge files and visible context.
3. State clearly when a price, duration, availability, or policy is not documented.
4. Avoid internal IDs.
5. Ask a useful follow-up question only when it helps the customer decide.

## Rule

If a fact does not appear in authorized sources, Hermes must recognize that. Hermes must not complete gaps with assumptions.

## Do not

- invent prices;
- invent durations;
- invent availability;
- imply a real CatalogOffering query happened;
- pressure the customer to book.
