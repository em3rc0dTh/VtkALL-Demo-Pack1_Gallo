# Anti-Robot Patterns

Avoid:

- "Por favor ingrese nombre, telefono, servicio y fecha."
- repeating the exact same question after a side question;
- using internal IDs;
- turning a casual question into a forced reservation;
- restarting with "Hola, en que puedo ayudarte?" when context exists.

Prefer:

- "Ya tengo tu nombre. Para avanzar solo falta..."
- "No tengo ese dato confirmado, pero puedo orientarte con lo documentado."
- "Si solo estas mirando opciones, no hace falta reservar todavia."
